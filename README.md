# 📸 Instagram UI Clone

A responsive, Instagram-inspired user interface built using **HTML5 and CSS3**.

This project recreates the visual layout of Instagram's home feed, including stories, posts, navigation, and profile suggestions. It focuses on practicing frontend development, CSS layouts, and responsive web design.

## 🚀 Features

- **Navigation Bar** – Instagram-inspired header with search input, navigation icons, and profile picture.
- **Stories Section** – Horizontally scrollable user stories with circular profile images.
- **Posts Feed** – Posts featuring user profiles, images, likes, captions, and comment counts.
- **Profile Sidebar** – Displays the current user's profile and suggested accounts.
- **Responsive Design** – Adjusts the layout for smaller screens using CSS media queries.
- **Modern Layout** – Uses CSS Flexbox for clean and organized page structure.

## 🛠️ Technologies Used

- **HTML5** – Page structure and semantic elements.
- **CSS3** – Styling, layouts, and responsive design.
- **Flexbox** – Alignment and layout management.
- **Media Queries** – Mobile-friendly layout adjustments.

## 💻 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/instagram-ui-clone.git
   ```

2. Navigate to the project directory:

   ```bash
   cd instagram-ui-clone
   ```

3. Open `index.html` in your web browser.

No installation or additional dependencies are required.

## 📱 Responsive Design

The layout adapts to different screen sizes.

**Desktop:**
- Navigation bar with search functionality layout.
- Main feed with stories and posts.
- Sidebar with profile information and suggested accounts.

**Mobile:**
- Simplified navigation.
- Full-width feed.
- Hidden sidebar and search field.
- Adjusted post and story layouts.

## ⚠️ Current Limitations

This project is a **static frontend UI clone**.

Features such as authentication, searching, liking posts, commenting, and following users are visual elements only and are not connected to a backend.
